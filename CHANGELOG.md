# Changelog

## 0.1.1

- The `extract` skills no longer describe Extract as a beta or as gated by domain. It works on any domain Zenrows has prepared, with any API key; `REQS007` means the domain isn't prepared yet, and `AUTH010` is the older code for the same case.

## 0.1.0

- First release: Zenrows MCP server (OAuth) and nine skills for OpenClaw: `zenrows`, `zenrows-scrape`, `zenrows-extract`, `zenrows-batch`, `zenrows-crawl`, `zenrows-map`, `zenrows-browser`, `zenrows-capture-api-calls` and `zenrows-getting-started`.
